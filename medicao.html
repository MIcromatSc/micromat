Como medir colônias How to Measure Colonies

Atualmente, existem diferentes formas de medir objetos em fotografias utilizando referências de escala conhecidas. Para isso, é necessário que um objeto presente na imagem possua dimensões conhecidas e esteja aproximadamente na mesma distância da câmera que o objeto a ser medido. Dessa forma, é possível estabelecer proporções e calcular medidas reais com maior precisão. Nowadays, there are different ways to measure objects in photographs using known scale references. For this, an object in the image must have known dimensions and be approximately at the same distance from the camera as the object being measured. This allows proportional relationships to be established and real measurements to be calculated more accurately.

1) Regra de três 1) Proportional Reasoning

É possível calcular o tamanho de uma colônia utilizando outro objeto de dimensão conhecida como referência. No caso das placas de Petri, normalmente utiliza-se uma régua posicionada próxima à placa durante a fotografia. It is possible to calculate the size of a colony using another object with known dimensions as reference. In the case of Petri dishes, a ruler positioned next to the plate during photography is commonly used.

Após ampliar a imagem, mede-se visualmente um trecho conhecido da régua e compara-se com o diâmetro da colônia. A partir dessa proporção, pode-se calcular o valor real do diâmetro. After zooming into the image, a known section of the ruler is visually measured and compared with the colony diameter. From this proportion, the real diameter value can be calculated.

É importante utilizar a mesma unidade de medida em todos os valores para evitar erros nos cálculos. It is important to use the same measurement unit for all values to avoid calculation errors.

Cálculo da Área Area Calculation

Após descobrir o diâmetro real da colônia, utilize a fórmula da área do círculo para calcular sua área. After determining the real colony diameter, use the circle area formula to calculate its area.

A = π · D2 4

Onde:

• A representa a área da colônia.
• π representa a constante pi.
• D representa o diâmetro real medido. Where:

• A represents the colony area.
• π represents the constant pi.
• D represents the measured real diameter.

2) ImageJ 2) ImageJ

O ImageJ é um software amplamente utilizado para análise de imagens científicas. Com ele, é possível medir diâmetros, áreas e outras características de colônias de forma mais precisa. ImageJ is a software widely used for scientific image analysis. It allows the measurement of diameters, areas, and other colony characteristics with greater precision.

O programa utiliza a escala da imagem para converter medidas em pixels para unidades reais, permitindo análises quantitativas mais confiáveis. The software uses the image scale to convert pixel measurements into real units, allowing more reliable quantitative analyses.
