Como medir colônias How to measure colonies

Atualmente, com a tecnologia, existem diversas maneiras de medir objetos em fotografias, desde que haja uma escala conhecida. Para isso, é necessário que algum objeto presente na imagem tenha um tamanho conhecido e esteja na mesma distância da câmera que o objeto a ser medido. Nowadays, technology allows several ways to measure objects in images, as long as a known scale is present. It is necessary that an object with known size is at the same distance from the camera as the object to be measured.

Por exemplo, não seria adequado usar o polegar para medir um prédio, pois estão em distâncias diferentes da câmera. For example, it would not be appropriate to use your thumb to measure a building, since they are at different distances from the camera.

1) Regra de três 1) Proportional reasoning

É possível calcular o comprimento de um objeto em uma foto utilizando outro objeto de tamanho conhecido como referência. It is possible to calculate the size of an object in an image using another object of known size as reference.

No caso das colônias, utiliza-se uma régua posicionada próxima à placa de Petri. Com a imagem ampliada, mede-se um centímetro da régua na foto e o diâmetro da colônia, estabelecendo uma proporção. In the case of colonies, a ruler is placed next to the Petri dish. By zooming into the image, one measures one centimeter on the ruler and the colony diameter, establishing a proportion.

A partir disso, pode-se calcular o diâmetro real da colônia. É importante utilizar a mesma unidade de medida em todos os valores. From this, the real colony diameter can be calculated. It is important to use the same unit for all measurements.

2) ImageJ 2) ImageJ

O ImageJ é um software que permite medir o diâmetro e a área de colônias de forma mais precisa. ImageJ is a software that allows precise measurement of colony diameter and area.

Você pode utilizá-lo para analisar imagens das placas e obter medidas mais confiáveis. It can be used to analyze plate images and obtain more reliable measurements.
